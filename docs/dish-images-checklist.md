# Danh sách ảnh món cần bổ sung
Thả file vào `assets/images/dishes/` **đúng tên** bên dưới là app tự dùng, không cần sửa code.
Định dạng: `.jpg` (hoặc `.png`). Nên chọn ảnh vuông ~600x600, **không có chữ/watermark**.

## Sau khi thêm ảnh, mở `pubspec.yaml` thêm 1 dòng vào mục assets:
```yaml
  assets:
    - assets/icons/
    - assets/icons/categories/
    - assets/images/
    - assets/images/banners/
    - assets/images/restaurants/
    - assets/images/dishes/          # <-- THÊM DÒNG NÀY
```
